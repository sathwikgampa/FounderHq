# `@founderhq/types`

## Overview

Shared TypeScript types, DTO contracts, enum definitions, and entity interfaces used across FounderHQ web frontend and monorepo packages.

## Exports

- `user.ts`: User profile, authentication state, and role types.
- `workspace.ts`: Multi-tenant workspace data models and subscription status.
- `rbac.ts`: Role-based access control roles and permissions schemas.
- `api.ts`: Standardized API success/error response envelopes and pagination metadata.
