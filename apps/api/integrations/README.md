# External Integrations Module (`apps/api/integrations`)

## Overview

Integration modules for Firebase and external third-party tools as specified in `docs/06_FOLDER_STRUCTURE.md`.

## Integrations

- `firebase/`: Firebase platform wrappers (Auth, Firestore, Storage, Messaging, Security)
- `gmail/`: Google Mail tool integration client
- `drive/`: Google Drive tool integration client
- `calendar/`: Google Calendar tool integration client
- `github/`: GitHub App tool integration client
- `slack/`: Slack bot tool integration client
- `stripe/`: Stripe billing integration client
