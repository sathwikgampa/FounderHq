# Firebase Integration Wrappers (`app/integrations/firebase`)

## Overview

Typed Python abstractions for Firebase Admin SDK (Authentication, Firestore Database, Cloud Storage, and App Check).

## Modules Included

- `auth.py`: Firebase Auth token verification and user management.
- `firestore.py`: Firestore multi-tenant database client initialization & repository helpers.
- `storage.py`: Firebase Cloud Storage bucket management wrapper.
- `app_check.py`: Firebase App Check token verification placeholder wrapper.
