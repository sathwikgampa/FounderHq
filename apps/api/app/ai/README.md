# AI Layer Framework (`app/ai`)

## Overview

Google ADK (Agent Development Kit) multi-agent system architecture placeholders for FounderHQ.

## Modular Sub-Systems

- **`planner/`**: CEO Planner executive orchestrator agent placeholder.
- **`finance/`**: CFO & Financial Modeling agent placeholder.
- **`growth/`**: Marketing & GTM Growth engine agent placeholder.
- **`talent/`**: HR, Hiring & Organizational design agent placeholder.
- **`operations/`**: COO Process & Execution agent placeholder.
- **`legal/`**: Legal & Compliance advisory agent placeholder.
- **`investment/`**: Fundraising & Investor Relations agent placeholder.
- **`memory/`**: Startup Memory (Short-term & Long-term context) placeholder.
- **`retriever/`**: RAG Vector Search & Document retrieval engine placeholder.
- **`prompts/`**: Prompt templates repository.
- **`schemas/`**: Typed Pydantic I/O schemas for AI tools and structured outputs.
- **`evaluators/`**: Agent evaluation benchmarks & governance placeholders.
