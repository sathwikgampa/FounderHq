# SELF REVIEW

Before marking a task complete, answer honestly:

1. Is this the best possible implementation?

2. Would a senior engineer approve this code?

3. Is there unnecessary complexity?

4. Is there unnecessary simplicity?

5. Can this fail?

6. Can it be demonstrated easily?

7. Is AI actually useful here?

8. Is this memorable?

9. Does this improve the judging score?

10. Would this impress investors?

If the answer to any question is "No",

improve the implementation before continuing.
